Wingthing manages durable agent runs and terminals on the wing where each existing workspace and provider login live. This service handles login, authorized wing discovery, and direct connection setup; your agent's MCP requests go straight between the connector and the selected wing, and the free tier does not use the hosted browser-terminal relay.

codex mcp add wingthing -- wt mcp connect --client codex
claude mcp add --scope user wingthing -- wt mcp connect --client claude

On each machine you want to manage, run wt login and wt start. Keep both peers on the same LAN or tailnet for the first direct release. Pro includes the hosted browser terminal and control relay. The native connector never silently changes from direct transport to relay transport.
