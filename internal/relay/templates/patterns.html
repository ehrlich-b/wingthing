manage agents where the work lives

Wingthing gives an agent one inventory and control plane for durable agents across machines. Pick the wing explicitly, run the work there, and let a person inspect or take over the same session when useful.

open the patterns skill

portal

The inventory and controls a person sees in the browser or an LLM sees through MCP.

wing

The execution runtime. A wing owns processes, workspaces, agent homes, and sessions.

roost

The self-hosted bundle from wt roost start: a portal and gateway with an embedded wing.

A session is a persistent terminal. A run is a headless task with a semantic result. An egg is the per-session sandboxed process behind a terminal.
