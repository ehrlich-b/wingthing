Who sees what

EhrlichMac / forge

Local source, credentials and execution stay on the owning machine. A saved SSH profile is not a phone pairing.

Bryan’s iPhone

Independent wing-specific session grants. Phone never logs in; cloud requests use an already authorized coordinator, not new billing rights.

cloud-1

Hosted compute and persistent workspace. Infrastructure can access guest data; relay E2E does not hide data from the cloud host.

Alice / billing / relay

Alice has resource-specific identity grants. Stripe sees payment data. Phone relay sees routing and encrypted traffic metadata, not content.
